### TASK
Classify the content into exactly one bucket and extract minimal metadata.

### CLASSES
- fact_about_user: assertions about the user (preferences, identity).
- todo: action items.
- watchlist: media to consume.
- buylist: items to purchase.
- reminder: time-anchored events.
- note: substantive thoughts, ideas (default fallback).
- reference: raw quotes, snippets, code.
- paper: formal documents (academic, longform).
- web: articles from URLs.

### REFUSAL CRITERIA
Set is_password_or_secret=true for: passwords, API keys, tokens, credentials, PINs.

### OUTPUT FORMAT
STRICT JSON ONLY. No prose. No preamble. No markdown blocks.

{
  "class": "<class>",
  "confidence": <0-1>,
  "title": "<short title, <60 chars>",
  "extracted_entities": ["entity1", ...],
  "date_mention": "<ISO 8601 or null>",
  "is_password_or_secret": <bool>
}
